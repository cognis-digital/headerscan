headerscan checks how secure a website's HTTP response headers are and gives them a letter grade, like a report card. You feed it a saved copy of the server's response, and it tells you which security protections are missing or misconfigured — things like clickjacking defenses, content-type protections, and transport-security settings. It scores the headers from 0 to 100 and assigns a grade from A+ down to F, with clear explanations of each issue. It is useful for web developers and security engineers who want a quick, offline, no-account-required check of their site's header hygiene.
